## Actions

### Button `button`

The one button for every action. Primary for the main action of a view, secondary for everything else, ghost for low-emphasis actions in toolbars, danger for destructive actions.

- **When to use:** Any clickable action. Use one primary button per view or dialog. Use an <a class="tx-btn"> only when it navigates.
- **Markup:** `ui/twinx/components/button/button.html`
- **Variants:** `tx-btn--primary` Main action. Brand fill, lifts to the menu-bar colour on hover.; `tx-btn--secondary` Default action. Card surface, line border, gold on hover.; `tx-btn--ghost` Low emphasis, no border until hover.; `tx-btn--danger` Destructive action (delete, reject).; `tx-btn--icon` Square icon-only button. Needs aria-label.; `tx-btn--sm` 28px high, for tables and dense toolbars.; `tx-btn--block` Full width, for narrow forms and mobile.
- **Accessibility:** Use <button type="button"> (or type="submit" in forms). Icon-only buttons need aria-label. Disabled state uses the disabled attribute, not a class.
- **Replaces old classes:** `.btn-primary`, `.btn-validate`, `.btn-next`, `.btn-create`, `.btn-outline`, `.btn-outline-icon`, `.btn-square`, `.icon-btn`, `.ad-btn`, `.pd-btn`, `.pp-btn`, `.rp-btn`, `.ub`

## Data display

### Context bar `context-bar`

One dark band of key facts about the record being viewed (promotion, market, period, owner), in the menu bar colours, with an optional gold action chip.

- **When to use:** Top of detail pages (result, workflow, logistics) to keep the record in view. One per page, under the page header.
- **Markup:** `ui/twinx/components/context-bar/context-bar.html`
- **Variants:** `tx-context-bar__chip` Gold action chip on the right.
- **Accessibility:** Facts are a <dl>: each fact is a <div> with <dt> label and <dd> value.
- **Replaces old classes:** `.res-summary`, `.wf-summary`, `.vs-summary`, `.res-fact`, `.res-chip`

### Data table `data-table`

Sticky uppercase header, hairline rows, gold row hover, numeric columns right-aligned. The wrapper scrolls sideways with a visible scrollbar on wide tables.

- **When to use:** Any tabular data. Put it in a card with tx-card__body--flush, add tx-pagination in the card footer. Use tx-table--dense for long lists and tx-table--lines for column lines.
- **Markup:** `ui/twinx/components/data-table/data-table.html`
- **Variants:** `tx-table-wrap` Scrolling frame. Set --tx-table-h to fix the height (sticky header scrolls inside).; `tx-table--dense` Shorter rows (32px).; `tx-table--lines` Column lines; headers are centred.; `tx-table--zebra` Alternate row tint.; `is-num` Cell class: right-aligned tabular figures (header follows).; `is-center` Cell class: centred.; `is-selected` Row class: selected row.; `tx-table__sticky-col` First column frozen while scrolling sideways.
- **Accessibility:** Use <th scope="col">. Give the table a <caption> (it can be visually hidden with tx-sr-only). Sortable headers use a button inside the th and aria-sort on the th.
- **Replaces old classes:** `.table-wrap`, `.ad-table-wrap`, `.rp-table-wrap`, `.vs-table-wrap`, `.wf-table-wrap`, `.cmp-metrics`

### KPI tile `kpi-tile`

A single figure with a micro label and an optional change indicator. Tiles sit in a row inside a summary card.

- **When to use:** Headline numbers (volume, uplift, budget). Put several in a tx-kpi-row. Tiles inside a summary card are the one allowed exception to 'no box in a box'.
- **Markup:** `ui/twinx/components/kpi-tile/kpi-tile.html`
- **Variants:** `tx-kpi-row` Responsive row of tiles.; `tx-kpi__delta--up` Positive change (green).; `tx-kpi__delta--down` Negative change (red).; `tx-kpi--accent` Gold top edge, for the one figure that matters most.
- **Accessibility:** Say the direction in words too (for example '+4.2% vs last year'), not only with colour or an arrow.
- **Replaces old classes:** `.rp-tile`, `.an-tile`, `.trend-tile`, `.rm-count`

## Feedback

### Empty state `empty-state`

Centred icon, one-line title, short help and an optional action, for a list or table with nothing in it yet.

- **When to use:** No data yet, no search results, or no permission. Say what to do next.
- **Markup:** `ui/twinx/components/empty-state/empty-state.html`
- **Variants:** `tx-empty--compact` Smaller, for inside a table cell or a small card.
- **Accessibility:** The icon is decorative (aria-hidden).

### Toast `toast`

A short message that slides in at the bottom right and fades after a few seconds. Also an inline alert for messages that stay on the page.

- **When to use:** Toast: confirm an action that happened ('Saved', 'Submitted for approval'). Alert: a message that must stay visible (validation summary, warning about data).
- **Markup:** `ui/twinx/components/toast/toast.html`
- **Variants:** `TwinX.toast(message, {tone})` JavaScript call; tone is success, danger, info or warning.; `tx-alert` Inline message block.; `tx-alert--success / --warning / --danger / --info` Tone of the alert.
- **Accessibility:** The toast region is aria-live="polite". Alerts that need immediate attention use role="alert".

## Forms

### Checkbox, radio and switch `checkbox`

Themed checkbox, radio and on/off switch, each with its label in one clickable row.

- **When to use:** Checkbox for independent options and table row selection; radio for one choice out of a few; switch for a setting that applies at once.
- **Markup:** `ui/twinx/components/checkbox/checkbox.html`
- **Variants:** `tx-check` Checkbox with label.; `tx-radio` Radio with label.; `tx-switch` On/off switch with label.; `tx-choice-group` Vertical or horizontal group with a legend.
- **Accessibility:** Use native inputs inside a <label>. Group radios in a <fieldset> with a <legend>. A switch is <input type="checkbox" role="switch">.
- **Replaces old classes:** `.checkbox`, `.fam-check`, `.msrp-check`, `.pp-toggle`

### Field `field`

Label, control and help or error text for text inputs, selects, textareas and search boxes. 36px controls with a gold focus ring.

- **When to use:** Every form control. Wrap the control in tx-field so label, help and error stay consistent. Use tx-field--inline for a label beside the control.
- **Markup:** `ui/twinx/components/field/field.html`
- **Variants:** `tx-input` Text, number, email, password, date inputs.; `tx-select` Native select with the themed chevron.; `tx-textarea` Multi-line text.; `tx-input-group` Input with a leading icon or a trailing unit.; `tx-field--error` Red border and message; set aria-invalid on the control.; `tx-input--sm` 28px control for tables and dense filters.
- **Accessibility:** Every control has a <label for>. Help and error text are linked with aria-describedby. Required fields use the required attribute and show '*' in the label.
- **Replaces old classes:** `.field`, `.field__control`, `.ue-field`, `.pp-field`, `.uf__box`, `.cfg-input`, `.cfg-select`, `.text-input`, `.sa-input`, `.vol-input`, `.vs-input`

### Filter bar `filter-bar`

A row of filter fields that grow to fill the width, with the search and reset actions at the end. Wraps on narrow screens.

- **When to use:** Above a table or list. Inside a card it sits flush with a hairline under it.
- **Markup:** `ui/twinx/components/filter-bar/filter-bar.html`
- **Variants:** `tx-filter-bar__fields` The fields; each tx-field inside grows from 160px.; `tx-filter-bar__actions` Buttons at the end.
- **Accessibility:** Wrap in <form role="search"> when it filters results.
- **Replaces old classes:** `.filters`, `.filters__fields`, `.filters__actions`, `.rp-filters`

## Layout

### App shell and menu bar `app-shell`

The page frame: a dark menu bar on the left (collapsed to 72px, opens in place on hover and pushes the content over, pin button keeps it open), a scrolling main column with tight padding, and a drawer below 900px. The theme picker lives in the menu bar footer.

- **When to use:** Every app page. Start from ui/patterns/page-template.html rather than writing the shell by hand. Change the brand badge, title and nav items only.
- **Markup:** `ui/twinx/components/app-shell/app-shell.html`
- **Variants:** `tx-nav-item.is-active` Current page in the menu (also set aria-current="page").; `tx-sidebar__section` Group label in the menu.; `data-tx-theme-open` Button that opens the colour theme menu (five CXO themes).; `html.is-nav-collapsed` Collapsed state, set before first paint by the head script.
- **Accessibility:** The menu bar is an <aside aria-label="Main menu"> with a <nav>. Collapsed items keep their label for screen readers (title + hidden text). Keyboard focus inside the collapsed menu opens it. The drawer closes on Escape.
- **Replaces old classes:** `.page`, `.main`, `.sidebar`, `.nav-item`, `.sidebar__brand`, `.sidebar__footer`, `.profile`, `.lang`, `.mobile-bar`, `.theme-menu`

### Card `card`

The one container for a block of content: a titled section with an optional toolbar, a body and a footer.

- **When to use:** Every block on a page. One container per block: never put a framed card inside another card. Tables, filter bars and forms inside a card sit flush (their frame is removed automatically).
- **Markup:** `ui/twinx/components/card/card.html`
- **Variants:** `tx-card__head` Title row with optional subtitle and actions on the right.; `tx-card__body` Padded content area.; `tx-card__body--flush` No padding, for tables that run edge to edge.; `tx-card__foot` Footer row (pagination, summary, actions).; `tx-card--elevated` Slight gradient and deeper shadow, for hero blocks.; `tx-section-title` A heading for a group of cards, without a frame.
- **Accessibility:** Give the card's title an id and set aria-labelledby on the <section>.
- **Replaces old classes:** `.card`, `.ad-card`, `.es-card`, `.res-card`, `.pd-card`, `.rp-card`, `.vs-card`, `.projects-card`

### Layout helpers and icons `layout`

Stack, row and grid helpers that space components with the spacing tokens, the stroke icon class, and small utilities (screen-reader-only text, muted text, numbers).

- **When to use:** Spacing between components inside a card or page body. Use these before writing page CSS. Grids collapse to one column below 900px.
- **Markup:** `ui/twinx/components/layout/layout.html`
- **Variants:** `tx-stack` Vertical stack, 16px gap (--sm 8px, --xl 24px).; `tx-row` Horizontal wrap row, 8px gap (--between, --end).; `tx-grid` Auto-fit grid, min column --tx-grid-min (220px); --2 and --3 fixed columns.; `tx-icon` Stroke icon (Lucide style svg, viewBox 0 0 24 24); --sm 14px, --lg 20px.; `tx-sr-only` Visually hidden, read by screen readers.; `tx-muted` Muted text colour.; `tx-num` Right-aligned tabular figures.
- **Accessibility:** Icons inside buttons are aria-hidden; the button carries the label.

### Page header `page-header`

Breadcrumb, serif page title, a one-line lead and actions on the right. Every page starts with one.

- **When to use:** Top of every page, first child of tx-main. Put the page's main actions (or a stepper) in tx-page-header__actions. Use tx-kicker for a small gold label above a title.
- **Markup:** `ui/twinx/components/page-header/page-header.html`
- **Variants:** `tx-breadcrumb` Trail of links; the last item is the current page.; `tx-kicker` Gold rule and tracked uppercase label above a title.; `tx-page-header__actions` Buttons or a stepper, aligned to the bottom right; wraps below on narrow screens.
- **Accessibility:** One <h1> per page, here. The breadcrumb is a <nav aria-label="Breadcrumb"> with aria-current="page" on the last item.
- **Replaces old classes:** `.page-header`, `.cfg-header`, `.res-header`, `.rp-header`, `.ad-header`, `.pd-header`, `.breadcrumb`, `.kicker`

## Navigation

### Pagination `pagination`

Page numbers with previous and next arrows; the current page has a gold border. Wraps on phones.

- **When to use:** Under a table, usually in the card footer next to a 'Showing x of y' summary.
- **Markup:** `ui/twinx/components/pagination/pagination.html`
- **Variants:** `tx-pagination__page[aria-current=page]` Current page.; `tx-pagination__gap` Ellipsis between page ranges.
- **Accessibility:** Wrap in <nav aria-label="Pages">. Mark the current page with aria-current="page". Arrows need aria-label.
- **Replaces old classes:** `.pagination`, `.pagination__page`, `.pagination__arrow`, `.table-footer`

### Stepper `stepper`

Compact step indicator for multi-step flows: done steps show a green check, the current step is a raised pill, upcoming steps are muted.

- **When to use:** Wizards such as create promotion → configure → simulate → submit. Put it in the page header actions or above the form.
- **Markup:** `ui/twinx/components/stepper/stepper.html`
- **Variants:** `tx-stepper__step--done` Completed step.; `tx-stepper__step--current` Current step (set aria-current="step").
- **Accessibility:** Use an <ol>. Mark the current step with aria-current="step". Done steps can be links back.
- **Replaces old classes:** `.stepper`, `.stepper__step`, `.stepper__item`

### Tabs and segmented control `tabs`

A tinted track with the active tab raised on the card surface. The same look serves page tabs (switch panels) and segmented controls (switch a view or a filter).

- **When to use:** Tabs switch between panels of one page. A segmented control switches a view of the same data (Monthly / Quarterly). Up to about 6 options; the track scrolls sideways if it runs out of room.
- **Markup:** `ui/twinx/components/tabs/tabs.html`
- **Variants:** `tx-tabs` Tab list; panels are tx-tab-panel elements. Behaviour from twinx.js (data-tx-tabs).; `tx-segmented` Same look, for radio-like view switches.; `tx-tabs--line` Underline style for tabs inside a card head.; `tx-tab__count` Small count after a tab label.
- **Accessibility:** role="tablist" / "tab" / "tabpanel" with aria-selected and aria-controls. twinx.js adds arrow-key navigation. A segmented control uses aria-pressed on its buttons.
- **Replaces old classes:** `.tabs`, `.tabs__list`, `.tab`, `.tab--active`, `.segments`, `.segment`, `.rp-tabs`, `.pd-tabs`, `.res-tabs`, `.art-tabs`, `.rf-tabs`, `.es-status`

## Overlays

### Modal dialog `modal`

Centred card on a dimmed, blurred backdrop with a gold top edge. Built on the native <dialog> element.

- **When to use:** Confirmations, short forms and details that need focus. Not for long flows (use a page). One primary button in the footer, on the right.
- **Markup:** `ui/twinx/components/modal/modal.html`
- **Variants:** `tx-modal--sm` 420px, confirmations.; `tx-modal--md` 560px, default.; `tx-modal--lg` 760px, forms and tables.; `data-tx-open / data-tx-close` Attributes that open and close a dialog with twinx.js, no page script needed.
- **Accessibility:** Native <dialog> with showModal() traps focus and closes on Escape. Give it aria-labelledby pointing at the title.
- **Replaces old classes:** `.ad-dialog`, `.es-dialog`, `.fam-dialog`, `.new-promo`, `.pp-panel`, `.rp-download`, `.sa-dialog`, `.umn-dialog`, `.us-dialog`, `.wf-comments`, `.wh-dialog`

### Tooltip `tooltip`

A small dark label under an element on hover and keyboard focus, set with one attribute.

- **When to use:** Explain an icon-only button or a truncated label. Not for essential information (it is hidden on touch).
- **Markup:** `ui/twinx/components/tooltip/tooltip.html`
- **Variants:** `data-tx-tooltip` Attribute holding the text.; `data-tx-tooltip-pos="top"` Show above instead of below.
- **Accessibility:** Also set aria-label on icon-only buttons; the tooltip is visual only.
- **Replaces old classes:** `[data-tooltip]`

## Status

### Badge `badge`

A small tinted pill with a dot that shows a status: approved, pending, in progress, rejected, draft.

- **When to use:** Statuses in tables, cards and headers. Not for actions (use a button) and not for counts on icons (use tx-count).
- **Markup:** `ui/twinx/components/badge/badge.html`
- **Variants:** `tx-badge--neutral` Draft, unknown, archived.; `tx-badge--progress` In progress, running (gold).; `tx-badge--pending` Waiting, needs action (amber).; `tx-badge--success` Approved, done, valid (green).; `tx-badge--danger` Rejected, failed, error (red).; `tx-badge--info` Iteration, version, tag (brand, no dot).; `tx-count` Round number on an icon button (notifications).
- **Accessibility:** The status must be in the text, never only in the colour.
- **Replaces old classes:** `.badge`, `.badge--progress`, `.badge--pending`, `.badge--iteration`, `.pr-badge`, `.notif__count`
